# Blog Posts

Write blog posts here as `.mdx` files.

The filename becomes the public URL:

```text
content/blogs/my-post.mdx -> /blogs/my-post
```

Required frontmatter:

```mdx
---
title: 'My post title'
description: 'A short summary for the blog index and metadata.'
author: 'Reese'
date: '2026-06-30'
---
```
